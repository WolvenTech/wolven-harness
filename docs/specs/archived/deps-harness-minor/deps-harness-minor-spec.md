# Minor dependency updates for harness-score, Biome and clack

**Source:** the confirmed ask: one PR bumping harness-score 1.6.5 → 1.12.0
(dev), @biomejs/biome 2.5.14 → 2.6.9 (dev), and @clack/prompts 1.8.1 → 1.9.0.
**Next:** After the Human approves → `code-plan` → `code-execute`, one wave.
**Named proof (this spec's own structural gate):** `proof-deps-harness-minor-spec-obligations`

## Repository grounding

| Surface | Present today | Role for this initiative |
|---------|----------------|----------------------------|
| `package.json` | yes | Holds the three version ranges to bump |
| `pnpm-lock.yaml` | yes | Regenerated by `pnpm install` |
| `biome.json` | yes | Its `$schema` may pin the Biome version |
| `src/setup/ui.ts` | yes | The only `@clack/prompts` consumer |
| `.harness-score.json` | yes | Score drops; left unchanged |
| `pnpm-workspace.yaml` | yes | Build allowlist and overrides; left unchanged |

## Surface walk

- **In scope:** `package.json`, `pnpm-lock.yaml`; the harness-score pin
  (`HARNESS_SCORE_VERSION` in `src/setup/harness-score.ts`, its tests, both
  copies of the harness-init `harness-score.md` reference, and the regenerated
  `known-forms.json`); and one `biome.json` exclude of `test/fixtures/**/*.md`,
  because Biome 2.6 formats markdown and would rewrite the deliberately
  malformed fixtures.
- **Out of mutate scope (unchanged):** `typescript`, `@types/node`, every
  other dependency, `.harness-score.json`, the `score` threshold, and
  `pnpm-workspace.yaml`.
