# Prefer project skills

Before using a skill, check for its project copy at either
`.agents/skills/<name>/SKILL.md` or `.claude/skills/<name>/SKILL.md`. Follow an
available project copy. Use the user-level copy only when neither project
copy exists.

Resolve relative references from the directory containing the selected
`SKILL.md`.
